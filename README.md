## 💙 Um pouco mais pessoal

Entre as linguagens que estudo, **Java é, pessoalmente, a minha favorita.**

Gosto da forma como a linguagem me força a pensar melhor sobre estrutura, organização e responsabilidades. Mais do que aprender sintaxe, estudar Java tem sido uma forma de construir uma base mais sólida em **programação, orientação a objetos e engenharia de software**.

Este repositório acompanha essa evolução.

```text
Não é só sobre aprender Java.
É sobre aprender a programar melhor.
```

## ✦ Sobre o projeto

Este repositório funciona como meu **playground de Java**: um espaço para testar conceitos, resolver exercícios, praticar POO e registrar minha evolução enquanto avanço nos estudos.

A proposta é simples:

**estudar → implementar → testar → entender → refatorar → evoluir**

## 🧠 Orientação a Objetos

A pasta `poo` é dedicada ao estudo de **Programação Orientada a Objetos** — uma das partes que mais quero aprofundar no Java.

```text
Classes → Objetos → Encapsulamento → Herança → Polimorfismo
```

O projeto `biblioteca` faz parte dessa etapa prática de aprendizado.
